# Privacy Policy – PerkPop

_Last updated: 2026-05-29_

## What PerkPop does

PerkPop is a Chrome extension that detects supported merchants in Google Search results and displays an inline cashback offer banner alongside those results.

## Data we collect

**None.** PerkPop does not collect, transmit, or share any personal data. Specifically:

- We do not read, log, or transmit your search queries.
- We do not track which merchants or results you click.
- We do not collect your browsing history.
- We do not create user accounts or profiles.

## Local storage

PerkPop uses `chrome.storage.local` exclusively to cache merchant offer data on your device. This cache contains only offer labels and cashback percentages from a static registry bundled with the extension. It is never sent to any server and is automatically invalidated after one hour.

## Host permissions

PerkPop requests permission to run on `https://www.google.com/*` solely to read the domain names of search result links and inject the cashback banner. No data from this permission is transmitted externally.

## Third-party services

PerkPop makes no network requests and integrates with no third-party services, analytics platforms, or advertising networks.

## Changes to this policy

If this policy changes in a future version, the updated policy will be included in the extension package and this file will be updated with a new date.
